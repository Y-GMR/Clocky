# Security Policy

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

---

## Vulnerability Reporting

Clocky utilizes kernel-mode driver interfaces (`WinRing0` via LibreHardwareMonitorLib) to access MSR and EC telemetry.

To report a vulnerability:
1. Do not file public GitHub issues for security vulnerabilities.
2. Send technical vulnerability details, reproduction steps, and impact assessment to `iwangpetradheerendra@gmail.com`.
3. Acknowledgments are provided within 48 hours, followed by a targeted patch release.
